## 필요 역량 vs 보유 (Required vs Available)

| 역량 | 필요도 | 팀 보유 | 상태 |
|---|---|---|---|
| React (프론트엔드) | 높음 | 능숙(전원) | ✅ 충족 |
| Spring (백엔드/API) | 높음 | 능숙(전원) | ✅ 충족 |
| 관계형 DB/데이터 모델링 | 높음 | 풀스택 보유 가정 | ✅ (functional-design에서 확인) |
| 인증/보안(Spring Security) | 중 | 풀스택 보유 가정 | ✅ 권고 사용 |
| 파일 업로드/저장(증빙·증서 이미지) | 중 | 풀스택 보유 가정 | ✅ |
| 로컬 배포/컨테이너 | 중 | 풀스택 보유 가정 | ◻ infra 단계에서 확인 |
| UI/UX 디자인 | 중 | 전담 없음 | ⚠ 갭 — 목업 단계로 보완 |
| 기획/PM | 중 | 겸임 | ◻ product 산출물이 보완 |

## 시사점

- 핵심 개발 역량(React·Spring)은 전원 능숙 → 병렬 작업·상호 리뷰 용이.
- 갭(디자인/UX)은 파일럿 UI를 단순하게 유지해 완화(project.md "범위를 좁게 유지" 원칙과 정합).
