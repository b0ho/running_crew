# Interaction Spec — LearnKK (파일럿)

> Inception · refined-mockups 단계 산출물 · 리드 design
> 상위 입력: `mockups.md`(동일 단계), `inception/user-stories/stories.md`

## 핵심 인터랙션

### IX-1 선착순 참여 (US-6a/6b)
- [참여하기] 클릭 → 로딩 → 결과 토스트.
  - 정원 여유: "참여 확정" + 대시보드 카드 추가.
  - 정원 마감(동시성 경쟁 패배 포함): "정원 마감 — 대기 신청됨".
  - **중복(상태별 메시지)**: 이미 확정 상태 → "이미 참여 중"; 이미 대기중 상태 → "이미 대기 중". (버튼 비활성)
- 실패/네트워크: 재시도 안내. 버튼은 중복 클릭 방지(요청 중 비활성).

### IX-2 회차 증빙 업로드 (US-9)
- (멘토) 회차 행 [파일 첨부] → 파일 선택 → 형식/크기 검증.
  - 통과: 업로드 진행률 → "인증됨" 상태 전환 + 증빙 이력 추가.
  - 형식 외/크기 초과: 인라인 오류("jpg/png/pdf, 10MB 이하만"), 업로드 중단.
  - **실패/네트워크 재시도**: 오류 메시지 옆 [다시 시도] 버튼 노출, 재클릭 시 동일 회차에 재업로드(버튼은 요청 중 비활성).

### IX-3 대기 승인 (US-8)
- (관리자) 대기 목록 항목 [승인]/[거절] → 확인 → 멘티 상태 갱신 + **알림 생성**.
- 낙관적 UI 대신 서버 확인 후 반영(정합성 우선).
- **처리 후 피드백**: 성공 토스트("승인됨"/"거절됨") + 해당 항목이 대기 목록에서 제거(목록 즉시 갱신). 실패 시 항목 유지 + 오류 토스트.

### IX-4 코호트 종료 → 수료·정산 (US-4, US-12, US-13)
- (멘토) [코호트 종료] → 확인 다이얼로그("종료 후 되돌릴 수 없음") → 상태 "종료됨".
  - 트리거: 각 멘티 수료 판정(출석≥80%) + 멘토 정산 조건 판정(전 회차 인증+보고서).
  - **후속 흐름**: 종료 완료 후 **코호트 종료 요약 화면**으로 이동 — 수료자 수/미수료 수 + 멘토 정산 조건 충족/미충족 메시지 표시. 멘티는 다음 접속 시 S7(수료 결과)에서 수료증/미수료 확인; 알림에도 통지.

### IX-5 최종 보고서 제출 (US-11)
- [제출] → 검증(빈 내용 방지) → "제출됨" 배지 → 관리자 보고서 이력 반영.

### IX-6 멤버 탭 조회 (US-3 멤버, mockups S4)
- (읽기 전용) 참여자 목록을 **닉네임 오름차순** 정렬로 표시, 각 행에 출석 요약(n/m).
- 항목 클릭 동작 없음(읽기 전용). **빈 상태**: "아직 참여자가 없어요" 안내.

## 상태·피드백 규칙

- 모든 상태 라벨: 색상 + 텍스트(+ 필요 시 아이콘) 병기.
- 파괴적 액션(코호트 종료)은 확인 다이얼로그 필수.
- 비동기 액션은 로딩 표시 + 완료 토스트.
- 폼 오류는 인라인(해당 필드 근처) 우선, 전역 오류는 상단 배너.
