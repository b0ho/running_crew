## 공통 레이아웃 & 내비게이션

- 반응형: 데스크톱 **상단 탭 바**, 모바일 **하단 탭 바**(rough 계승).
- 탭: 홈(내 코호트) · 코호트 탐색 · 알림/공지 · 내 정보. 관리자 역할 시 `관리자` 탭 추가.
- 시각 톤: 밝은 배경 + 중립 그레이 + **강조색 1개**(예: 인디고). 상태는 색상+텍스트 병기.

## 화면 정제 (rough 대비 변경점 명시)

### S1 로그인/회원가입 (US-1, US-2)
- 회원가입 필드: 이메일 / 성명 / 닉네임 / 비밀번호. 중복 이메일 오류는 **이메일 필드 하단** 인라인 메시지(색상+아이콘+텍스트).
- 로그인 실패: 폼 상단 배너.

### S2 홈: 내 코호트 대시보드 (US-2, US-10) — 첫 화면
- 코호트 카드: 제목 / 진도 % / 출석 n/m / [들어가기]. **빈 상태**: "참여 중인 코호트가 없어요 — 코호트 탐색하기" CTA.
- 멘토 역할 사용자: [ + 새 코호트 개설 ] 노출.

### S3 코호트 탐색 & 참여 (US-6a, US-6b)
- 카드: 제목 / 정원 n/N / 상태(모집중·마감). 모집중=[참여하기], 마감=[대기 신청].
- 참여 결과 토스트: "참여 확정" / "정원 마감 — 대기 신청됨" / 상태별 중복("이미 참여 중" 또는 "이미 대기 중")(색상+텍스트).

### S3b 내 신청 상태 (US-7)
- 목록: 코호트 / 상태(대기중⏳·확정✅·거절✖, 텍스트 라벨 동반). 상태 변경 시 알림 탭 배지.

### S4 코호트 상세 (US-5, US-9, US-10, US-11) — 탭 구성
- 탭: 공지 · 진도·출석 · **멤버** · 보고서.
- 진도·출석: 회차 목록(회차 n / 상태 인증·미인증 / (멘토)[파일 첨부 업로드]).
- **멤버 탭(신규, Q2=A)**: 참여자 **닉네임 + 출석 요약(n/m)** 간단 목록.
- 보고서 탭: [최종 보고서 제출] → S4b.

### S4b 최종 보고서 제출 (US-11)
- 자유 서식 텍스트 + 선택적 파일 첨부(이미지/pdf ≤10MB). 제출 후 "제출됨" 배지.

### S5 코호트 개설/수정·종료 (US-3, US-4) — rough 정합
- 필드: 제목 / 설명 / 정원 / 기간(시작~종료) / **회차 수(신규 추가, rough 화면5 누락 정합)**.
- 상세 화면에 [코호트 종료] 액션(확인 다이얼로그) → 상태 "종료됨", 수료·정산 판정 트리거.

### S6 관리자 (US-8, US-14, US-15)
- 탭: 대기 승인 · 운영 지표 · 증빙 이력 · 보고서 이력(4개 분리 뷰).
- 대기 승인: 대기 신청 목록 각 [승인]/[거절] → 처리 후 목록에서 제거 + 토스트 + 멘티 알림 생성.
- 운영 지표: 완주 코스 수 / 출석률 / 수료율 / 증서 발급 수 카드. **빈 상태** 안내.

> **관리자 시드(US-0)**: 최초 관리자 계정은 UI 화면이 아니라 **DB 시드 스크립트/마이그레이션**으로 부트스트랩한다(회원가입 경로로 관리자 부여 불가). 파일럿 테스트 시 시드된 관리자 계정으로 로그인.

### S8 코호트 종료 요약 (US-4, US-12, US-13)
- 멘토가 코호트 종료 후 이동하는 요약 화면: 수료자 수 / 미수료 수, 정산 조건 충족/미충족 메시지. 멘티에게는 알림 + S7에서 개별 결과 확인.

### S7 수료 결과 (US-12, US-13)
- 멘티: 수료 시 수료증 이미지 미리보기 + [다운로드]. 미수료 시 "미수료 — 부족 항목" 안내.
- 멘토: "정산 조건 충족 ✅"(충족) / "미충족 — 부족 항목"(부분 충족) 메시지.
