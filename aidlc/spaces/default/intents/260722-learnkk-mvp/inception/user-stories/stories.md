# User Stories — LearnKK (사내 멘토링 통합 플랫폼 파일럿)

> Inception · user-stories 단계 산출물 · 리드 product (mob: design·developer·quality 통합 반영)
> 상위 입력: `requirements-analysis/requirements.md` (FR-1~FR-11), `practices-discovery/team-practices.md`, `ideation/rough-mockups/wireframes.md`
> 형식: "As a <역할>, I want <목표> so that <이유>" + 수용 기준(AC). FR 추적 표기.
> 공통 AC(접근성): 상태 표시는 색상+텍스트 병기, 인터랙티브 요소는 키보드 접근·포커스 가능(파일럿 수준, wireframes 접근성 원칙 계승).

## 역할 모델 (mob: developer OBJECTION 반영)

- **역할 방식(결정)**: 멘토/멘티는 **컨텍스트 역할** — 코호트를 개설하면 그 코호트의 멘토, 참여하면 멘티. 별도 신청 없이 행위로 결정.
- **관리자**는 **명시적 부여 역할**로, 회원가입 경로로 만들 수 없다.

### US-0 역할 모델·관리자 시드 (RBAC 선행)
- As a 시스템, I want 컨텍스트 역할(멘토/멘티)과 명시적 관리자 역할을 두기 so that 권한을 통제한다.
- 수용 기준: 최초 관리자 계정은 **시드(부트스트랩)**로 생성; 일반 회원가입은 관리자 권한 부여 불가; 코호트 개설자는 해당 코호트 멘토로 자동 멤버십.

## 계정 (FR-1)

### US-1 회원가입
- As a 직원, I want 이메일·성명·닉네임·비밀번호로 가입하기 so that 플랫폼을 이용한다.
- AC: 유효 이메일 검증; 중복 이메일 거부 시 **이메일 필드 하단에 오류 문구 표시**; 비밀번호 BCrypt 해싱; 그 외 정보 미수집; 오류 메시지는 색상+텍스트 병기(색상만으로 구분하지 않음).

### US-2 로그인
- As a 사용자, I want 로그인하기 so that 내 코호트 대시보드로 진입한다.
- AC: 성공 시 내 코호트 대시보드 이동; 잘못된 자격 증명 시 폼 상단에 오류 메시지 노출; **참여 코호트 0건이면 빈 상태 안내 + '코호트 탐색' 유도**; 대시보드 카드에 진도/출석 요약 표기(wireframe 화면2 정합).

## 코호트 개설·운영 (FR-2, FR-6) — 멘토

### 코호트 상태 전이 (정의)
- 코호트 상태: **모집중 → 진행중 → 종료됨**. "종료됨"은 멘토가 **"코호트 종료" 액션**을 수행할 때 전이된다. 종료 액션 시 수료(US-12)·정산(US-13) 판정이 계산되고, 지표(US-14)의 "완주 코스 수"에 집계된다.

### US-3 코호트 개설
- As a 멘토, I want 제목·설명·정원·기간·**회차 수**를 정해 코호트를 개설하기 so that 과정을 모집한다.
- AC: 정원≥1, 회차≥1 정수; 개설 즉시 "모집중"; **개설 시 회차 레코드 N건 생성**(회차는 1급 엔티티, **초기 상태=미인증(예정)**); 개설자는 멘토로 자동 멤버십.

### US-4 코호트 수정·종료
- As a 멘토, I want 내 코호트를 수정하거나 종료하기 so that 최신 상태를 유지하고 과정을 마감한다.
- AC: 멘토 본인만 수정/종료 가능; 저장 후 변경 내용이 상세/목록에 반영; 이미 확정 인원 초과로 정원 축소 시 경고; **"코호트 종료" 액션 수행 시 상태가 "종료됨"으로 전이되고 수료·정산 판정이 트리거됨**.

### US-5 공지 작성
- As a 멘토, I want 코호트 공지(외부 미팅 링크 포함)를 올리기 so that 멘티에게 안내한다.
- AC: 공지 작성/노출; 외부 링크 클릭 가능; 공지 없을 때 빈 상태 안내.

## 참여 (FR-3, FR-4) — 멘티/관리자

### US-6a 선착순 자동 참여 (walking-skeleton 대상)
- As a 멘티, I want 정원 여유가 있는 코호트에 참여하기 so that 바로 학습을 시작한다.
- AC: 정원 여유 시 즉시 확정; **중복 참여 거부**(이미 확정/대기중 상태에서 재신청 차단, 상태별 메시지); 순차 경계 — N번째 신청까지 확정, 정원 도달 후 US-6b로 전환; 참여 결과(확정/마감) 즉시 피드백(색상+텍스트 병기, 키보드 접근 가능).
- 의존 메모: US-6a는 단독 출하 가능(스켈레톤); US-6b(대기·동시성)는 US-6a 위에 얹힌다(의도된 분할 의존).

### US-6b 정원 마감 대기 신청 (동시성)
- As a 멘티, I want 정원 마감 코호트에 대기 신청하기 so that 승인 시 참여한다.
- AC: 마감 시 "대기 신청" 등록; **동시 N+1 요청 시 정확히 N명만 확정**(DB 유니크 제약 + 비관적 락, 동시성 테스트로 검증); 정원 초과 확정 없음.

### US-7 신청 상태·알림 확인
- As a 멘티, I want 내 신청 상태(대기중/확정/거절)와 알림을 확인하기 so that 진행을 안다.
- AC: 신청 상태 변경(확정/승인/거절) 시 **해당 멘티에게 알림 레코드가 생성**되고 알림 탭에 노출; 멘티가 알림 탭에서 통지 이력 열람 가능; 상태·알림은 **색상+텍스트 병기, 키보드 접근·포커스 가능**.

### US-8 대기 승인
- As a 관리자, I want 정원 마감 코호트의 대기 신청을 승인/거절하기 so that 초과 참여를 통제한다.
- AC: 관리자 역할만 접근 가능; 승인/거절이 멘티 상태에 즉시 반영되고 **승인/거절 시 멘티 알림 레코드 생성**(US-7에서 열람); 승인/거절 버튼은 키보드 접근 가능; **범위 외 명시**: 대기 신청 취소, 확정 취소 시 대기자 자동 승격, 거절 후 재신청은 이번 파일럿에서 다루지 않음.

## 진도·출석 (FR-5) — 멘토/멘티

### US-9 회차 출석 증빙 인증
- As a 멘토, I want 회차별로 증빙 파일을 첨부하기 so that 출석을 인증한다.
- AC: 허용 = 이미지(jpg/png)+문서(pdf), 파일당 ≤10MB; **형식 외 거부(예: .exe)와 크기 초과 거부(예: 11MB)를 각각 처리**; 첨부 즉시 해당 회차 "인증됨"; 증빙 이력 1건 적재; 파일은 로컬 서버 파일시스템(웹루트 밖 볼륨)에 저장; 회차 상태(인증/미인증)는 색상+텍스트 병기, 업로드 컨트롤 키보드 접근 가능.

### US-10 진도·출석 확인
- As a 멘티, I want 회차별 진도·출석 상태를 확인하기 so that 내 진행을 파악한다.
- AC: 회차 목록과 각 회차 출석 상태(인증/미인증) 표시(색상+텍스트); 대시보드 요약과 일치.

## 보고서·수료·정산 (FR-7, FR-8, FR-9)

### US-11 최종 보고서 제출
- As a 멘토/멘티, I want 코호트 종료 시 자유 서식 보고서(+선택 첨부)를 제출하기 so that 활동을 기록한다.
- AC: 제출 후 "제출됨"; 첨부 파일 제약 US-9와 동일; 관리자 보고서 이력에 표시; 파일 로컬 저장.

### US-12 수료증 수령
- As a 멘티, I want 출석 80% 이상이면 수료증 이미지를 받기 so that 수료를 증빙한다.
- AC: **수료 산식 = 인증 출석 회차 수 / 전체 회차 수 ≥ 0.80**(예: 5회차 중 4회=80% 수료, 4회차 중 3회=75% 미수료); **판정 시점 = 멘토의 코호트 종료 액션(US-4) 시 계산**; 수료 시 수료증 이미지 발급·다운로드; 미달 시 "미수료 — 부족 항목 안내"; 수료/미수료 결과는 색상+텍스트 병기.

### US-13 정산 조건 충족 확인
- As a 멘토, I want 코호트 정상 종료(전 회차 인증 + 보고서 제출) 시 "정산 조건 충족" 메시지를 받기 so that 강의 수행을 기록한다.
- AC: 조건 충족 시 메시지 표시(실제 결제·정산 없음); **부분 충족(회차 1건 미인증 또는 보고서 미제출) 시 미표시 + 부족 항목 안내**; 판정 시점 = 코호트 종료 액션 시.

## 지표·이력 (FR-10, FR-11) — 관리자

### US-14 운영 지표 조회
- As a 관리자, I want 운영 지표를 조회하기 so that 성과를 판단한다.
- AC(관리자 역할만 접근; 집계 정의 명시):
  - **완주 코스 수** = 상태가 "종료됨"(멘토 종료 액션 완료, US-4)인 코호트 수
  - **출석률** = 인증된 (회차×확정멘티) / 전체 (회차×확정멘티)
  - **수료율** = 수료자 수 / 확정 참여 멘티 수
  - **증서 발급 수** = 발급된 수료증 수
  - 데이터 0건일 때 빈 상태 안내.

### US-15 증빙·보고서 이력 조회
- As a 관리자, I want 증빙 이력과 최종 보고서 이력을 각각 조회하기 so that 활동을 확인한다.
- AC: 관리자 역할만 접근; 두 이력이 분리 뷰로 조회; 각 항목의 첨부 파일 열람/다운로드 가능.
