## Contribution

테스트 가능성/QA 렌즈로 리드 초안(stories.md)의 수용 기준을 검증 가능성 기준으로 점검했다. 요구(FR-1~11)와 team-practices(핵심 도메인 80%, 동시성 테스트, Testcontainers, 스모크)에 비추어 다음을 발견했다.

### 검증 가능한 항목 (양호)
- US-6(선착순): "동시 N+1 → N만 확정, 중복 참여 불가"는 requirements FR-3와 일치하며 동시성 테스트로 검증 가능한 명확한 기준. (핵심 도메인 80% 대상)
- US-9(증빙): "허용 형식/크기 외 거부, 첨부 즉시 인증됨, 이력 1건 적재"는 negative case가 명시되어 검증 가능.
- US-12(수료): "출석≥80% 발급, 미달 미수료"는 경계 판정 대상으로 명확.

### 누락된 negative/edge 케이스 (수용 기준 보강 필요)
1. **정원 경계**: US-6에 N/N+1은 있으나 **단일 요청 정확 경계**(N번째 확정 성공, N+1번째 대기 전환)의 순차 케이스가 없다. 동시성뿐 아니라 순차 경계도 명시 필요.
2. **중복 참여**: "불가"만 있고 판정 시점(이미 확정/대기중 상태에서 재신청 거부)의 상태별 케이스가 모호하다.
3. **파일 형식/크기 거부**(US-9): "형식 외/크기 초과" 각각의 거부 케이스 분리 명시 필요(예: 11MB pdf 거부, .exe 거부, 0바이트 파일).
4. **출석 경계**(US-12): **79% vs 80% 경계**를 명시적 예시로 넣어야 한다(회차 총수에 따른 반올림/버림 정책 — 예: 5회차 중 4회=80%, 4회차 중 3회=75%). 현재는 판정 산식(반올림 규칙)이 없어 테스트 작성 시 해석 여지가 크다.
5. **대기 거절**(US-8): 거절 후 재신청 가능 여부, 확정 정원 복구(취소 시 대기 승격) 흐름이 없다. 파일럿 범위면 "범위 외" 명시라도 필요.
6. **정산 판정**(US-13): "모든 회차 인증 + 보고서 제출"의 부분 충족(회차 1건 미인증, 보고서 미제출) negative 케이스가 없다. FR-9 "미충족 시 미표시"를 스토리 수용 기준에도 반영해야 검증 가능.

### 너무 모호해 테스트하기 어려운 항목
- **US-14** "지표가 실제 데이터와 일치": 검증 오라클이 불명확. 각 지표(완주 코스 수/출석률/수료율/증서 수)의 **정의와 집계 산식**을 수용 기준에 명시해야 검증 테스트를 쓸 수 있다.
- **US-2/US-7** "오류 안내"/"알림 통지": 통지 채널·형태가 불명확. 파일럿에서는 최소한 "상태 필드 변경이 조회에 반영"처럼 관측 가능한 기준으로 서술 필요.
- **US-4/US-10**: 수용 기준 자체가 없다(추적표엔 있으나 검증 기준 부재).

### 파일럿 스코프 정합
- team-practices의 Testcontainers/동시성 테스트는 US-6·US-9·US-12·US-13(핵심 도메인)에 집중하면 80% 목표와 정합. 나머지 CRUD성 스토리(US-4/US-5/US-10 등)는 스모크 수준으로 충분 — 이 우선순위를 스토리 메모에 남기면 후속 build-and-test가 명확해진다.

## Positions

- **RECOMMENDATION**: US-12 수용 기준에 출석률 **산식과 반올림 정책** + 79%/80% 경계 예시를 추가한다(테스트 오라클 확정).
- **RECOMMENDATION**: US-9에 형식 거부·크기 초과 거부를 **각각의 케이스**로 분리 명시한다.
- **RECOMMENDATION**: US-13에 정산 조건 **미충족(부분 충족) negative 케이스**를 수용 기준으로 추가한다.
- **RECOMMENDATION**: US-6에 순차 경계(N번째 확정/N+1 대기) 및 중복 재신청 상태별 거부를 명시한다.
- **OBJECTION**: US-14 "실제 데이터와 일치"는 검증 불가 수준으로 모호 — 각 지표의 집계 정의를 명시하지 않으면 인수 테스트를 작성할 수 없다.
- **RECOMMENDATION**: US-4/US-10에 최소 수용 기준을 부여한다(현재 공란).
- **RECOMMENDATION**: 대기 취소→승격, 거절 후 재신청 여부는 파일럿 범위 안팎을 명시(범위 외라면 명시적 제외).
