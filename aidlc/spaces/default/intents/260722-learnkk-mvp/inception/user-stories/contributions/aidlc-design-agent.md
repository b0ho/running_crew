## Contribution

UX/디자인 렌즈로 리드 초안(stories.md, personas.md)을 wireframes.md·user-flow.md·requirements.md와 대조 검토했다. 전반적으로 스토리와 와이어프레임/플로우의 정합성은 양호하나(로그인→대시보드, 선착순/대기, 증빙 첨부, 수료/정산 분리), UX 관점에서 몇 가지 누락·비검증 항목을 확인했다.

### 정합성 확인 (일치)
- US-2 로그인→내 코호트 대시보드: user-flow 흐름2, wireframe 화면2와 일치.
- US-6/US-7/US-8 선착순·대기·승인: 화면3/3b, 흐름1과 일치(대기중/확정/거절 3상태 매핑 정확).
- US-9 증빙 "파일 첨부" 방식: 화면4의 "텍스트 메모 아님" 주석과 일치.
- US-11~US-13 수료(멘티 80%) vs 정산(멘토 전 회차+보고서) 분리: 화면7·흐름4와 일치.

### 정합성 불일치 / 누락 (UX-critical)
1. **접근성 수용 기준 소실**: wireframes 접근성 메모는 "상태(모집중/마감·인증/미인증)를 색상만이 아니라 텍스트로도 표기, 키보드 포커스 순서"를 원칙으로 못박았고 NFR-3(반응형)도 명시돼 있으나, 어떤 스토리 AC에도 반영되지 않았다. 상태 표시가 다수인 파일럿(US-6/7/9/10/12)에서 이 원칙은 회귀되면 안 됨.
2. **빈 상태(empty state) 스토리 부재**: 대시보드(참여 코호트 0), 탐색 결과 0건, 알림 없음, 관리자 지표 초기 데이터 0의 화면 정의가 없다. "worst-case 우선 설계" 원칙상 파일럿에서도 최소 문구가 필요.
3. **알림/공지 조회(멘티) 스토리 부재**: wireframe 공통 탭 `알림/공지`와 화면3b가 상태 변경 통지를 명시하나, 멘티가 알림 탭을 열람하는 스토리는 없다(US-5는 멘토 작성 관점). US-7 AC의 "통지"가 어디서 어떻게 보이는지 미검증.
4. **대시보드 요약 카드 스토리 부재**: 화면2는 코호트 카드에 "진도 60% 출석 8/10 + 들어가기"를 노출하나, US-10(진도·출석)은 코호트 상세 관점뿐이라 대시보드 요약 표기가 커버되지 않음.
5. **멤버 탭 스토리 부재**: 화면4의 `멤버` 탭(참여자 목록)에 대응하는 스토리가 없음(파일럿 중요도 낮음, 확인 필요).
6. **와이어프레임↔스토리 필드 불일치**: US-3/FR-2는 "회차 수"를 개설 입력으로 두나, 화면5 개설 폼에는 회차 필드가 없다(제목/설명/정원/기간만). refined-mockups 전에 정합 필요.

### 수용 기준의 UX-검증가능성
- **AC 누락**: US-4(코호트 수정), US-10(진도·출석 확인)에 AC가 없어 UX 테스트 불가. 수정 후 반영 확인, 회차별 진도/출석 상태의 관측 가능한 표시로 AC 필요.
- **비관측 표현**: US-2 "오류 안내"는 무엇을·어디서 보이는지 불명확 → "잘못된 자격 증명 시 폼 상단/필드에 오류 메시지 노출, 성공 시 대시보드 이동"처럼 관측 가능하게.
- **피드백 상태 부재**: US-6 참여하기 클릭 시 즉시/대기 결과 피드백(성공·마감 전환)의 관측 기준이 없음.

## Positions

- **P1 (OBJECTION)**: 상태 표시가 있는 스토리(US-6/US-7/US-9/US-10/US-12)에 접근성 AC를 최소 한 줄씩 추가해야 한다 — "상태는 색상+텍스트 병기, 인터랙티브 요소는 키보드 접근/포커스 가능". wireframe이 확립한 원칙이 스토리에서 소실되는 회귀는 막아야 한다. (완전 WCAG 준수가 아닌, 이미 합의된 원칙의 AC화)
- **P2 (OBJECTION)**: US-4·US-10에 관측 가능한 수용 기준을 추가해야 한다. AC 없는 스토리는 quality가 UX 테스트를 설계할 수 없다.
- **P3 (RECOMMENDATION)**: 빈 상태(대시보드/탐색/알림/지표 0건)를 US-2·US-6·US-14에 AC 한 줄로 흡수하거나 소형 스토리 1개(US-EmptyStates)로 신설. 파일럿 규모에 맞춰 최소 문구 수준.
- **P4 (RECOMMENDATION)**: 멘티 알림/공지 조회 스토리 신설(또는 US-7 AC에 "알림 탭에서 상태 변경 이력 열람" 명시)로 화면3b/`알림·공지` 탭 커버.
- **P5 (RECOMMENDATION)**: 대시보드 코호트 카드의 진도/출석 요약 표기를 US-10 또는 US-2 AC에 포함(화면2 정합).
- **P6 (RECOMMENDATION)**: US-3 "회차 수" 입력과 화면5 개설 폼의 필드 불일치를 정합 — 스토리를 소스로 두고 refined-mockups에서 회차 필드 반영. `멤버` 탭은 파일럿 필수 여부를 product와 확인해 스토리화 또는 스코프-아웃 명시.
- **P7 (RECOMMENDATION)**: US-2 "오류 안내", US-6 참여 결과 피드백을 관측 가능한 표현으로 구체화(오류 위치/문구, 성공·대기 전환 피드백).
